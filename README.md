# 🏋️‍♂️ Smart Gym Workout AI

An AI-powered fitness trainer that detects exercises using pose estimation and provides real-time feedback.

## 🚀 Features
- Exercise detection (Squats, Pushups, Jumping Jacks)
- Real-time tracking using webcam
- AI model trained on pose data
- Personalized workout suggestions

## 🧠 Tech Stack
- Python
- OpenCV
- MediaPipe
- Scikit-learn

## 📂 Project Structure
- train_model.py → train AI model
- test_live.py → real-time detection
- coach.py → workout logic
- tutorials/ → demo exercises

## ▶️ How to Run

```bash
pip install -r requirements.txt
python test_live.py
